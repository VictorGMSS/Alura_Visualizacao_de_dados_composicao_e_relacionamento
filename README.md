# Alura_Visualizacao_de_dados_composicao_e_relacionamento

# 📊 Data Visualization: Composition & Relationship Charts

Projeto desenvolvido durante meus estudos de Visualização de Dados com foco em gráficos de composição e relacionamento utilizando Python e bibliotecas amplamente utilizadas em Data Science.

---

## 🚀 Sobre o Projeto

Este projeto explora técnicas de visualização voltadas para análise de composição, correlação e relacionamento entre variáveis, utilizando gráficos que facilitam a interpretação visual e a comunicação eficiente de dados.

Além da criação das visualizações, também foram aplicadas práticas de design visual, personalização e boas práticas em Data Visualization para tornar os gráficos mais claros e informativos.
